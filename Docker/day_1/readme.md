# Task

1. Create a Docker image: Write a Dockerfile to containerise a Flask or FastAPI application.
2. Define an environment variable: Use an environment variable (e.g., NAME) to personalize the application. Allow users to pass this variable at runtime.
3. Display the variable: Update the app to display the variable in a simple HTML page with a greeting message.
4. Build and run the container: Build the image and run the container, passing the NAME variable, and verify that the app displays the greeting on the web page.
